# GUI 应用程序指南

## 概述

MacinTouch GUI 是 macOS 菜单栏应用，驱动核心以 in-process 方式内嵌，无需 `sudo`。通过系统权限对话框自动引导所需权限。

## 编译与运行

```bash
# 编译（调试版）
make gui-debug

# 运行
make gui-run-debug
# 或直接打开
open build/MacinTouchApp.app

# 编译发布版并安装到 /Applications
make gui
make gui-install
```

## 首次使用

1. 打开应用，菜单栏出现触摸图标
2. 系统弹出**辅助功能权限**请求 → 在系统设置中允许
3. 点击菜单栏图标，查看设备状态
4. 如显示"Input Monitoring"权限提示 → 在系统设置中允许
5. 连接 ILITEK 触摸屏，状态变为绿色"Active & Running"

## 界面说明

### 菜单栏面板

点击菜单栏图标展开面板：

| 区域 | 内容 |
|------|------|
| 标题栏左侧 | 驱动状态（绿色=运行中，红色=未激活）；未激活时显示快捷操作按钮（Grant Permission 或 Restart） |
| 标题栏右侧 | ⚙ 打开设置窗口；✕ 关闭面板（不退出程序） |
| 设备状态 | ILITEK 设备连接状态；当前目标显示器分辨率 |
| 底部 | "Quit MacinTouch" 退出整个程序 |

### 设置窗口

点击设置图标（⚙）打开设置窗口：

#### Permissions 权限
- 辅助功能权限状态与授权入口
- 刷新权限状态按钮

#### Devices 设备
- 已连接显示器列表（可选择触摸映射目标）
- ILITEK 设备连接状态

#### Gestures 手势配置

**四指手势**
- 启用/禁用
- 最小手指间距（40–200px）
- 滑动触发距离（30–150px）
- 最小滑动速度（50–500px/s）

**捏合缩放**
- 启用/禁用
- 触发距离阈值（10–50px）
- 缩放灵敏度（0.1–1.0×）

**滚动**
- 平滑滚动开关
- 自然滚动方向开关
- 平滑系数（0.1–1.0，仅平滑模式生效）

**右键触发**
- 长按时长（0.3–1.5s）
- 最大允许移动量（5–30px）

保存/重置按钮在有未保存更改时激活。

#### Startup 开机启动
- 登录时自动启动开关

#### About 关于
- 版本信息、设备规格、功能列表

## 配置持久化

配置保存在：
```
~/Library/Application Support/MacinTouch/config.json
```

CLI 驱动和 GUI 应用共享同一配置文件。通过 GUI 修改配置后，重新运行 CLI 驱动也会使用相同设置。

## 权限说明

| 权限 | 用途 | 获取方式 |
|------|------|----------|
| 辅助功能 | 模拟鼠标点击和键盘快捷键 | 系统设置 → 隐私与安全性 → 辅助功能 |
| 输入监控 | 访问 HID 设备 | 系统设置 → 隐私与安全性 → 输入监控 |

GUI 不需要 `sudo`，但需要以上两项系统权限。

## 故障排查

**设备状态显示"Not Found"**
1. 确认触摸屏已连接
2. 点击菜单栏状态旁的"Restart →"快捷按钮
3. 执行 `swift tools/core/device-check-simple.swift` 确认设备可被检测到

**状态一直显示"Inactive"**
1. 若提示"Grant Permission →"，点击后在系统设置中授予辅助功能权限
2. 权限已授予但仍 Inactive，点击"Restart →"重启驱动

**手势不响应**
1. 确认对应手势在 Gestures 标签页中已启用
2. 检查 macOS 系统设置中的手势是否与驱动冲突（系统设置 → 触控板）

**配置修改不生效**
- 确认已点击"Save"保存配置
- 点击"Restart Driver"重新加载
